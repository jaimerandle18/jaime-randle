# Jaime Randle — Portfolio

Personal portfolio of Jaime Randle, Software Engineer (Buenos Aires, Argentina).

Bilingual (EN/ES), light/dark with a drag-to-reveal theme handle, a 3D coverflow
of selected work, smooth momentum scroll and pastel visuals.

## Stack

- Next.js 16 (App Router) · React 19 · TypeScript
- Tailwind CSS v4
- Framer Motion · Lenis (smooth scroll)
- Deployed on Vercel

## Selected work

- **Data Jury** — web + mobile app for lawyers to rate courts (live on both stores)
- **Simple-AI** — AI agents that answer a business's WhatsApp customers
- **Prode Vamo Arriba** — realtime World Cup 2026 prediction game

## Development

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
```
